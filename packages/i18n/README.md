# @ieum/i18n

en·ko 번역 카탈로그. **프론트와 백엔드가 같은 파일을 읽는다.**

## 규칙 (docs/architecture/i18n.md)

1. **en 이 원본이다.** ko 는 같은 키 집합을 100% 채운다. 한쪽이라도 비면 CI 실패.
2. 키는 의미 기반: `issue.action.assign`. 문장을 키로 쓰지 않는다.
3. 문자열 조합 금지. 복수형은 항상 ICU 로 표현한다.
4. 번역문에 마크업을 넣지 않는다. 강조·링크는 컴포넌트 보간으로.
5. 기능을 만들면서 en·ko 를 **같은 커밋에** 채운다.

## 네임스페이스

| 파일 | 범위 |
|---|---|
| `common.json` | 버튼·상태·공통 문구 |
| `auth.json` | 로그인·2FA·세션 |
| `errors.json` | 서버 에러 코드 → 표시 문구 |
| `projects.json` | 프로젝트 |

## 검사

```bash
pnpm i18n:check    # 키 동기화 + ICU 문법 + 플레이스홀더 일치 + 하드코딩 탐지
```
